## 1. Navigation Structure

### 1.1 Primary Navigation (Desktop)

```
[Atelier Logo / Name]     Home  |  Kurse  |  Galerie  |  Atelier  |  Canvas     [DE | EN]
```

- Logo links to `/` (or `/en/` when in EN mode)
- Nav items are text links, no dropdowns
- Language switcher: text toggle `DE | EN` — right-aligned
- Active page: underline indicator (1px, Deep Teal)
- Sticky on scroll: nav becomes `position: fixed`, background `Crème/95% opacity`, backdrop-blur
- Mobile: hamburger icon (right side) → full-screen overlay menu

### 1.2 Mobile Navigation

Trigger: Hamburger icon (top-right)

Overlay opens full-screen (Crème background):
```
[X close]

Home
Kurse
Galerie
Atelier
Canvas

DE | EN
```

- Each link closes the overlay on click
- Close button top-right
- Overlay uses slide-in from right (200ms ease-out)
- No nested menus

### 1.3 Footer Navigation

```
[Atelier Name]     Kurse  |  Galerie  |  Atelier  |  Canvas  |  Datenschutz  |  Impressum

© 2025 Atelier [Name]. Alle Rechte vorbehalten.     DE | EN
```

## 3. User Flows

### FLOW 1: New Visitor — First Visit to Home

```
[Browser opens /]
        ↓
[Intro animation plays — brush stroke reveal of atelier name]
[Duration: ~2.4s]
[LocalStorage key set: atelier_intro_seen = true]
        ↓
[Hero section fully visible]
[Two CTAs: "Kurse entdecken" | "Galerie ansehen"]
        ↓
User scrolls OR clicks CTA
        ↓
  [If scrolls] → Content reveals progressively (fade-in on scroll)
  [If "Kurse entdecken"] → Navigate to /kurse
  [If "Galerie ansehen"] → Navigate to /galerie
```

**Repeat visitor (intro_seen = true):** Animation skipped. Hero loads immediately.

---

### FLOW 2: New Visitor — Second or Later Visit

```
[Browser opens /]
        ↓
[No animation — Hero loads immediately]
        ↓
[Same page content as Flow 1, minus intro animation]
```

---

### FLOW 3: Course Discovery → Inquiry

```
User on /kurse (or arrives from Home CTA)
        ↓
[Course catalogue displayed]
[Filters visible: Technik | Zielgruppe]
        ↓
User optionally applies filter
  [Filter: Aquarell] → Only Aquarell courses shown
  [Filter: Kinder] → Only courses for Kinder & Jugendliche shown
  [No filter] → All courses shown
        ↓
User reads course card
[Card shows: Technique tag | Title | Short description | Schedule | Price | "Mehr erfahren"]
        ↓
User clicks "Mehr erfahren" on a course card
        ↓
Navigate to /kurse/[slug]
        ↓
[Course detail page loads]
[Full description, schedule, level, materials, price, instructor, gallery]
        ↓
User decides to inquire
        ↓
Clicks "Jetzt anfragen" CTA
        ↓
  [WhatsApp option selected] →
    Opens WhatsApp with pre-filled message:
    "Hallo, ich interessiere mich für den Kurs: [Course Title]. Können Sie mir mehr Informationen geben?"
    Target: atelier WhatsApp number
        ↓
  [Email option selected] →
    Opens mailto: with pre-filled subject:
    Subject: "Kursanfrage: [Course Title]"
    Body: "Guten Tag, ich interessiere mich für den Kurs..."
    Target: atelier email address
```

**Error states:**
- Course not found (invalid slug): redirect to `/kurse` with toast: "Kurs nicht gefunden."
- No courses match filter: empty state with message "Keine Kurse gefunden. Alle Kurse ansehen →"

### FLOW 4: Artwork Discovery → Purchase Inquiry

```
User on /galerie (or arrives from Home featured works)
        ↓
[Masonry gallery loads]
[First 24 items shown. Pagination for more.]
        ↓
User optionally applies filter
[Technik filter | Ersteller filter]
        ↓
User clicks artwork card
        ↓

        ↓
[Artwork detail page loads]
[Image gallery (swipeable), title, technique, dimensions, description, price or "Preis auf Anfrage"]
        ↓
  [If interested in buying] →
    Clicks "Interesse? Schreib uns auf WhatsApp"

    "Hallo, ich interessiere mich für das Werk: [Artwork Title]. Ist es noch verfügbar?"
        ↓

    Clicks browser back OR "Weitere Werke ansehen" link

```

**Error states:**
- Artwork not found: redirect to `/galerie` with toast: "Werk nicht gefunden."

### FLOW 5: Community Canvas — Drawing & Submission

```
User navigates to /canvas
(From nav, from Home teaser CTA, or direct link)
        ↓
[Page loads]
[Community gallery displayed: approved submissions in mosaic grid]
[CTA visible: "Jetzt mitmachen" / "Join now"]
        ↓
User clicks "Jetzt mitmachen"
        ↓
[Drawing tool panel opens/expands]
[Canvas: 400×400px white surface]
[Tool controls: brush size (S/M/L), color palette (atelier colors + 6 extras), undo, clear]
        ↓
User draws
  [Undo] → removes last stroke
  [Clear] → resets canvas (with confirm dialog: "Alles löschen?")
        ↓
User clicks "Einreichen" / "Submit"
        ↓
[Name input appears: "Dein Name (optional)" / "Your name (optional)"]
[Submit button: "Einreichen" / "Submit"]
        ↓
User fills name (or leaves empty) and clicks Submit
        ↓
[Loading state: spinner]
        ↓
  [Success] →
    Image uploaded to Supabase Storage
    Record created in DB: status = pending
    Success message displayed:
    DE: "Danke! Dein Werk wird geprüft und erscheint bald in der Galerie."
    EN: "Thank you! Your artwork is being reviewed and will appear in the gallery soon."
    Drawing tool resets after 3 seconds
        ↓
  [Error — upload failed] →
    Error message:
    DE: "Upload fehlgeschlagen. Bitte versuche es erneut."
    EN: "Upload failed. Please try again."
    Submit button re-enabled. User can retry.
        ↓
[Admin approves in Supabase dashboard]
[submission.status updated: pending → approved]
        ↓
[Gallery updates in real-time via Supabase Realtime]
[New approved artwork appears in mosaic with fade-in animation]
```

## 4. Scroll Behaviour & Animation Triggers

| Element | Trigger | Behaviour |
|---|---|---|
| Hero | Page load (first visit) | Brush stroke intro animation (~2.4s) |
| Hero | Page load (return visit) | Immediate display, no animation |
| Nav | Scroll past Hero | Becomes sticky with Crème/95% bg |
| Section headings | Enter viewport (IntersectionObserver) | Fade-in + slight translate-y (20px → 0) |
| Course cards | Enter viewport | Fade-in, staggered (100ms delay per card) |
| Artwork masonry items | Enter viewport | Fade-in, staggered |
| Featured works | Enter viewport | Parallax: image scrolls at 0.8× page scroll speed |
| Canvas gallery items (new) | Supabase Realtime event | Fade-in from opacity 0 |
| Scroll progress indicator | On scroll | Thin 1px line (Deep Teal) grows across top of viewport |

**All animations respect `prefers-reduced-motion: reduce`.** When set, all transitions and animations are disabled. Elements appear instantly.

## 5. CTA Hierarchy (per page)

Every page has one primary CTA. Secondary CTAs support but do not compete.

| Page | Primary CTA | Secondary CTA |
|---|---|---|
| Home | "Kurse entdecken" | "Galerie ansehen" |

| Galerie | Click artwork card | Filter controls |
| Artwork Detail | "Interesse? Schreib uns" (WhatsApp) | Email alternative |

## 6. Empty States

Every list or gallery must handle the empty state gracefully.

| Context | Empty State Message (DE) | Action |
|---|---|---|
| Kurse — no filter results | "Keine Kurse für diese Auswahl gefunden." | "Alle Kurse anzeigen →" (clears filter) |
| Kurse — no courses in CMS | "Aktuell keine Kurse verfügbar. Schreib uns für mehr Infos." | WhatsApp CTA |
| Galerie — no filter results | "Keine Werke für diese Auswahl gefunden." | "Alle Werke anzeigen →" |
| Canvas — no approved submissions | "Noch keine Einreichungen. Sei der Erste!" | "Jetzt mitmachen" CTA |

## 7. Pre-filled WhatsApp & Email Templates

### Course Inquiry — WhatsApp
```
Hallo, ich interessiere mich für den Kurs «[COURSE_TITLE]». Könnten Sie mir mehr Informationen zum nächsten Termin geben? Danke!
```
URL: `https://wa.me/[WHATSAPP_NUMBER]?text=[encoded_message]`

### Artwork Inquiry — WhatsApp
```
Hallo, ich interessiere mich für das Werk «[ARTWORK_TITLE]». Ist es noch verfügbar und was ist der Preis? Danke!
```

### Course Inquiry — Email
```
Subject: Kursanfrage: [COURSE_TITLE]
Body: Guten Tag, ich interessiere mich für den Kurs «[COURSE_TITLE]» und würde gerne mehr Informationen erhalten. Mit freundlichen Grüssen
```

### Artwork Inquiry — Email
```
Subject: Anfrage: [ARTWORK_TITLE]
Body: Guten Tag, ich interessiere mich für das Werk «[ARTWORK_TITLE]». Bitte teilen Sie mir mit, ob es noch verfügbar ist. Mit freundlichen Grüssen
```

**Implementation note:** WhatsApp number and email address must be stored as environment variables (`NEXT_PUBLIC_WHATSAPP_NUMBER`, `NEXT_PUBLIC_CONTACT_EMAIL`). Never hardcoded in components.
